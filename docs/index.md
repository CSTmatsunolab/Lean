## このゼミの目標

1. Lean で簡単な定理（等式変形、論理、集合、帰納法）を自分で証明できるようになる
2. Mathlib（Lean の数学ライブラリ）で必要な定理を検索して使えるようになる
3. 「証明が正しいことを機械で保証する」とはどういうことかを説明できるようになる

## 進め方

- **最初の 3 回:** ブラウザのゲーム [Natural Number Game](https://adam.math.hhu.de/#/g/leanprover-community/NNG4) で、Lean の操作に慣れます。
- **4 回目以降:** MIL を 1 回に 1〜2 節ずつ読みます。各回の担当者が内容を説明し、演習を全員でその場で解きます。
- **教科書は英語です:** わからない英文は、担当者がゼミで解説します。数学の内容は大学 1〜2 年レベルなので、英語が理由で詰まったときは遠慮なく質問してください。
- **予習:** 次回の範囲の Lean ファイルを開いて、例題を一通り動かしてきてください（演習は解けなくてもかまいません）。
- **詰まったら:** 質問の場所は未定です（Slack・Discord・GitHub Issues などを予定）。英語ができる人は [Lean Zulip](https://leanprover.zulipchat.com/) の `#new members` もおすすめです。

詳しい範囲は [日程]({{ '/schedule/' | relative_url }})、担当回の準備は [発表の準備]({{ '/presenting/' | relative_url }}) を見てください。

## 前提知識について

- プログラミング経験も、型理論の知識も不要です。
- 高校数学と、大学 1 年程度の「集合と論理」があれば十分です。MIL の 3〜4 章で一緒に復習します。
- 環・束・距離空間・ε-N 論法などの用語も出てきますが、使う性質は MIL の中でそのまま与えられます。未履修でも、その場で確認しながら進められます。
- 『Types and Programming Languages』（TAPL）などの型理論の教科書を先に読む必要はありません。Lean の土台になる「命題は型、証明はその型の値」という考え方は、第 3 回の補講で扱います。
