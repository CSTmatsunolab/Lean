## 日本語の資料

- [Theorem Proving in Lean 4 日本語訳](https://aconite-ac.github.io/theorem_proving_in_lean4_ja/) — Lean の土台（依存型理論）を学ぶ定番の本の和訳
- [Lean by Example](https://lean-ja.github.io/lean-by-example/) — コード例で学ぶ Lean（lean-ja）
- [数学系エンドユーザーのためのLean入門](https://shosonoda.github.io/lean-math-note/) — 数学で Lean を使う人向けの講義資料（園田翔）
- [数学系のための Lean 勉強会](https://haruhisa-enomoto.github.io/lean-math-workshop/) — スライドと演習
- [lean-ja](https://lean-ja.github.io/) — 日本語コミュニティ（[リンク集](https://lean-ja.github.io/links/)に Discord の案内あり）

## 調べ物に使うもの

- [Loogle](https://loogle.lean-lang.org/) — 名前や式の形で Mathlib の定理を検索
- [LeanSearch](https://leansearch.net/) — 自然言語（英語）で Mathlib の定理を検索
- [Mathlib のドキュメント](https://leanprover-community.github.io/mathlib4_docs/)
- [タクティクのチートシート (PDF)](https://leanprover-community.github.io/papers/lean-tactics.pdf)
- [Mathlib のタクティク一覧](https://leanprover-community.github.io/mathlib4_docs/tactics.html)
- [Lean Language Reference](https://lean-lang.org/doc/reference/latest/)

## もっと先へ

- [Lean Game Server](https://adam.math.hhu.de/) — NNG 以外のゲーム（集合、論理など）
- [Lean Zulip](https://leanprover.zulipchat.com/) — 世界中の Lean ユーザーが集まるフォーラム（英語）
