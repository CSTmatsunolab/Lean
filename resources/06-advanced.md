# 発展的な資料

基礎（[01](01-roadmap.md) のステップ 3 まで）が終わってから読むもの。

## メタプログラミング・タクティク作成

- **Tactic Programming Guide** — https://github.com/mirefek/lean-tactic-programming-guide
  自作タクティクの入門。初心者向けに書かれている。
- **Metaprogramming in Lean 4** — https://github.com/arthurpaulino/lean4-metaprogramming-book
  Web 版: https://leanprover-community.github.io/lean4-metaprogramming-book/
  より本格的。先に FPIL のモナドの章を読んでおくこと。日本語訳（アーカイブ済み）: https://github.com/lean-ja/lean4-metaprogramming-book-ja

## 型理論・Lean の基礎

- **Type Checking in Lean 4** — https://ammkrn.github.io/type_checking_in_lean4/ カーネルの仕組み、外部型検査器
- **The Type Theory of Lean** (Mario Carneiro) — https://github.com/digama0/lean-type-theory/releases
- **Lean 4 の論文** — https://lean-lang.org/papers/lean4.pdf
- **Lean の型理論の概略** — https://leanprover-community.github.io/lean-perfectoid-spaces/type_theory.html
- **Introduction to Homotopy Type Theory** (Egbert Rijke) — https://arxiv.org/pdf/2212.11082
- **HoTT Book**（第 1 章が依存型理論の入門になる） — https://homotopytypetheory.org/book/
- **Coq (Rocq) リファレンスの CIC の章** — https://rocq-prover.org/doc/master/refman/language/cic.html
